## The facts (verified)

A271942 = "Triangle read by rows: T(n,k) is the number of bargraphs of semiperimeter n having
width k (n>=2, k>=1)" (Emeric Deutsch, May 21 2016), offset 2, keyword `tabl` (row `n` is
`k = 1..n-1`), 91 terms. Its Cf. is `A082582, A145904, A271943`. It cites none of the entries
below, and they cite it:

- A001263's approved formula (A001263 #792): `Sum_{k=1..n} T(n,k)*binomial(m+n-k-1, n-1) =
  A271942(n+m, n)` for `n, m >= 1`, and `Cf. A005408, A005891, A063490, A160747, A271942.`
- A063490 and A160747 (approved): `a(n) = A271942(n+4, 4)` and `a(n) = A271942(n+6, 5)`.
  A005891's `a(n) = A271942(n+4, 3)` is in review.

A bargraph of width `k` with column heights `c_1..c_k` has semiperimeter
`k + c_1 + Sum_{i>=2} max(0, c_i - c_{i-1})`, the width plus the number of blocks of the
castle with those heights, so column `k` counts the castles of width `k` by blocks.

1. **Columns k = 2..5 are A005408(n-3), A005891(n-4), A063490(n-4), A160747(n-6)**, for all
   listed terms of the four entries (66, 47, 41 and 34), counting the bargraphs directly.
2. **A001263's formula** gives all 91 listed terms of A271942.

Verified 2026-11-01 against the live data; script below. `bin/python/tower_t_cores.py` checks
the four columns and A001263's formula against all 11175 terms of the A271942 b-file.

def bargraphs(n, k):             # width k, semiperimeter n = k + (vertical edges) / 2
    H = n - k
    f = {(h, h): 1 for h in range(1, H + 1)}   # (last height, vertical edges so far)
    for _ in range(k - 1):
        g = {}
        for (h, v), c in f.items():
            for h2 in range(1, H + 1):

                    g[h2, v + abs(h2 - h)] = g.get((h2, v + abs(h2 - h)), 0) + c
        f = g
    return sum(c for (h, v), c in f.items() if v + h == 2 * H)
