```
From _Chaz Reid_, Oct 16 2026: (Start)
Sum_{k=1..n} T(n,k)*binomial(m+n-k-1, n-1) is the number of castles of width n with m blocks, of any height (Project Euler, Problem 502: Counting Castles); see A005408, A005891, A063490, A160747 for n = 2..5.
Proof: with G(x,y) = Sum_{n,k>=1} T(n,k)*x^n*y^k, B = G(x/(1-y), y) satisfies x*B^2 - (1-x-y-x*y)*B + x*y = 0, which is equation (2) of Deutsch and Elizalde for bargraphs (castles) with x marking width and y marking up steps (blocks).
(End)
```

**LINKS:**

```
Emeric Deutsch and Sergi Elizalde, <a href="https://arxiv.org/abs/1609.00088">Statistics on bargraphs viewed as cornerless Motzkin paths</a>, arXiv:1609.00088 [math.CO], 2016.
Project Euler, <a href="https://projecteuler.net/problem=502">Problem 502: Counting Castles</a>.
```

## Proof

T(n,k) counts Dyck paths of semilength n with k peaks, so C = 1 + G satisfies
C = 1 + x*C*(C - 1 + y) (first-return decomposition; a return with empty inside is a peak).
That is G = x*(G + 1)*(G + y). Put x/(1-y) for x: (1-y)*B = x*(B + 1)*(B + y), which expands to
Deutsch and Elizalde's x*B^2 - (1-x-y-x*y)*B + x*y = 0 (their eq. (2); x marks H steps, the
width, and y marks U steps, which for a castle are its blocks). Both sides are the unique power
series in x without constant term solving the quadratic, so the castles of width n have g.f.
[x^n] B = Sum_k T(n,k)*y^k/(1-y)^n by blocks, whose coefficient of y^m is the formula.
