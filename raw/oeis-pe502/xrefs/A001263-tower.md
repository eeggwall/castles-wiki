## Identity (verified)

A001263 = triangle of Narayana numbers T(n,k) = C(n-1,k-1)*C(n,k-1)/k, 1 <= k <= n,
offset 1, read by rows: `1, 1,1, 1,3,1, 1,6,6,1, 1,10,20,10,1, ...`.

Throughout this draft, "N(w,k)" denotes the Narayana number (this entry's T(w,k)), and the
tower count is written in words to avoid clashing with the entry's symbol T.

A **tower** of width w (see below) has, by number of blocks, the generating function

    sum_b (number of towers of width w with b blocks) x^b
        = ( sum_{k=1..w} N(w,k) x^{k-1} ) / (1 - x)^w.

Equivalently, the number of towers of width w with exactly b blocks is

    sum_{k=1..w} N(w,k) * C(b + w - k, w - 1).

This is verified for w = 1..7 by `python3 tower.py` (DP == closed form == brute force).  It
is a generating-function identity, **not** a "peaks" bijection: a direct peaks refinement
was tested and does not factor this way, so do not state a peaks interpretation.

## The tower object (self-contained definition)

A **tower** of width w is a stack of unit-height blocks on a line of w cells: each block
is a horizontal segment of adjacent cells at some height, every block rests on the floor or
on the block directly below it (nothing floats or overhangs), and two blocks in the same
row are separated by at least one empty cell.  Equivalently a tower is a column-height
vector (c_1,...,c_w) of nonnegative integers; its number of blocks is the number of
maximal horizontal runs, c_1 + Sum_{i=2..w} max(0, c_i - c_{i-1}).
