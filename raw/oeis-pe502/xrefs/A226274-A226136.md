## The facts (verified)

A226274 = "Position of 1/n in the ordering of the rationals given by application of the map
t -> (1+t,-1/t), cf. A226130" (M. F. Hasler, Jun 01 2013), offset 1, 28 terms:
`1, 9, 31, 100, 317, 1000, 3150, 9918, …, 90548996937472`. Hasler's comment: "It is seen that
the unit fraction 1/n appears as the last term produced in the (3n-3)th iteration", hence its
formula `a(n) = s(3n-3)` where `s(k) = Sum_{j=0..k} A226275(j)`; also an o.g.f.,
`x(1 + 4*x - 7*x^2 + 4*x^3 - x^4)/((1 - x)(1 - 4*x + 3*x^2 - x^3))`. Both formulas rest on the
observation, which the entry does not prove. Its Cf. is
`A226271, A226275, A226080, A226081, A226130`, with no A226136. It has no links and no
program other than Hasler's PARI one, marked "illustrative purpose only".

A226136 = the positions of the positive integers in the same ordering. Its approved formula
block (A226136 #29) gives `a(n) = 1 + Sum_{k=0..n-2} A226275(k) = 1 + s(n-2)`: the integer `m`
is the first term of generation `m - 1`. A226136 cites A226274
(`Cf. A226130, A226131, A226137, A226274, A226275.`); A226274 has no link back.

The Reid link is `a226136.pdf`, "Proof of Barker's Conjecture for A226136", on A226136 (read
2026-11-03). It numbers the generations from 1, so its `g(k)` is Hasler's iteration `k - 1`.
Its words over `T(x) = x + 1` and `S(x) = -1/x` are applied left to right to 1, and its
backward continued fraction is `[[c_1, ..., c_m]] = c_1 - 1/[[c_2, ..., c_m]]`. The paper
never mentions unit fractions, so fact 3 below has to be written out in the entry.

Kimberling and Moses (Fibonacci Quarterly 52 (2014), no. 5, 136-150; read 2026-11-03),
Example 4.2, p. 141, is this tree: "Let S be the tree generated by these rules: 1 ∈ S, and if
x ∈ S then x + 1 ∈ S, and if x ∈ S and x ≠ 0, then −1/x ∈ S", with the generation sizes
`1, 2, 3, 3, 5, 7, 10, 15, 22, ...` satisfying `|g(n)| = |g(n−1)| + |g(n−3)|` for `n ≥ 7`. It
says nothing about 1/n. A226136 links it in the form copied below.

1. **A226274(n) = A226136(3n-1) - 1 for n >= 1** (all 28 listed terms). From the two formulas:
   `A226136(3n-1) = 1 + s(3n-3) = 1 + A226274(n)`. So the formula is equivalent to the entry's
   own `a(n) = s(3n-3)`. It holds at `n = 1` too (`A226136(2) - 1 = 1`), so it needs no range.
2. **Reading:** 1/n is the last term of generation `3n - 3` and the integer `3n - 1` is the
   first term of generation `3n - 2`, so in the ordering 1/n is immediately followed by
   `3n - 1` (1/1 by 2, 1/2 by 5, 1/3 by 8).
3. **Hasler's observation is proved** by the Reid link. For `n >= 2`,
   `1/n = 1 - 1/x` with `x = n/(n-1) = [[2, ..., 2]]` (`n - 1` 2's). By Lemma 5, `x` is the
   value of the A-word `w = T(STT)^(n-2)` (`r_0 = 1`, `r_1 = ... = r_(n-2) = 2`), so 1/n is
   the value of the node `wST = T(STT)^(n-2)ST`, of length `3n - 3` (Lemma 3, type B). It is
   the largest node of its length in the order with `T < S`: a node of length `>= 3` begins
   with T (by Lemma 3 the only nodes beginning with S are S and ST), an S that is not the
   last letter is followed by T (type C has the single child T), and STS ends a word (type D
   has no children). So a node `u > wST` would first differ from `wST` with an S in place of
   a T; that T follows the initial position, an S, or an ST, and the three cases contradict
   the three facts in turn (the third because the T after ST sits at position `3k + 1 <=
   3n - 5`, so `u` would end before length `3n - 3`). By Theorem 8, 1/n is the last element
   of `g(3n-2)`; by Corollary 9(c), `3n - 1` is the first element of `g(3n-1)`. This proves
   fact 2, and with it Hasler's `a(n) = s(3n-3)` and, through Theorem 1(a), his o.g.f. (the
   trisection of `x(1+x)(1+x^2)^2/(1-x-x^3)`, minus `x/(1-x)`).
4. **Recurrence:** `(1 - x)(1 - 4x + 3x^2 - x^3) = 1 - 5x + 7x^2 - 4x^3 + x^4`, so
   `a(n) = 5a(n-1) - 7a(n-2) + 4a(n-3) - a(n-4)` for `n >= 6`, signature `(5,-7,4,-1)`; it
   fails at `n = 5` (`318`), because the o.g.f.'s numerator has degree 5. No order-3 form
   holds from `n = 4`: `a(n) = 4a(n-1) - 3a(n-2) + a(n-3) + 1` holds for `n >= 5` and fails at
   `n = 4` (`99`). The signature line is the one for the eventual recurrence, as on A226136
   (signature `(1,0,1)`, recurrence from `n = 7`), and the o.g.f. carries the first terms, so
   neither formula line needs another range.
5. **Program:** `t(n) = A003410(3n-1)` satisfies `t(n) = 4t(n-1) - 3t(n-2) + t(n-3)` (the
   trisection of `x^3 = x^2 + 1`), with `t(0), t(1), t(2) = 1, 3, 10` (A003410(-1) = 1 by its
   recurrence run backward). `a(n) = t(n) - 1` for `n >= 2` (A226136 = A003410 from index 4),
   and `a(1) = 1 = t(1) - 2`. The program returns all 28 terms; a(10^5), 165439 bits, takes
   0.8 s (Python 3.11, 2026-11-03).
