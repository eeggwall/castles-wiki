## The facts (verified)

A226136 = "Positions of the positive integers in the ordering of rational numbers as
generated by the rules: 1 is in S, and if nonzero x is in S, then x+1 and -1/x are in S",
offset 1, 35 terms: `1, 2, 4, 7, 10, 15, 22, 32, 47, 69, 101, 148, 217, …, 973982`.
Its only formula is Barker's conjecture: `a(n) = a(n-1) + a(n-3)` for `n > 6`, g.f.
`-x*(x+1)*(x^2+1)^2/(x^3+x-1)`. Its Cf. is A226080 only.

A003410 = "Expansion of (1+x)(1+x^2)/(1-x-x^3)", offset 0, `1, 2, 3, 5, 7, 10, 15, 22, 32,
47, 69, 101, …`. Deutsch's comment (Feb 15 2010): "a(n) is the number of binary words of
length n that have no pair of adjacent 1's and have no 0000 subwords."

1. **A226136(n) = A003410(n) for 4 <= n <= 35** (all listed terms).
2. **Barker's conjectured g.f. is the g.f. of A003410 minus 1 + x + x^2 + x^3**:
   `(1+x)(1+x^2)/(1-x-x^3) - (1+x)(1+x^2) = x(1+x)(1+x^2)^2/(1-x-x^3) = -x(x+1)(x^2+1)^2/(x^3+x-1)`.
   So Barker's conjecture is equivalent to `a(n) = A003410(n)` for `n >= 4` (with
   `a(1), a(2), a(3) = 1, 2, 4`, one less than `A003410(1..3) = 2, 3, 5`).
3. **Castle reading of A003410** (proved): for `n >= 4`, A003410(n) is the number of castles of
   width `n` and height 2 in which no two columns of height 2 are adjacent and every run of
   columns of height 1 has length at most 3. The castle's second row is a binary word with no
   `11` and no `0000` (Deutsch's words); for `n >= 4` every such word contains a 1, so every
   word is the second row of exactly one castle. (For `n <= 3` the all-zero word is one of
   Deutsch's words but gives the flat row, which has no column at height 2.)

Verified 2026-10-04 by brute force (words and castles, `n <= 15`) and SymPy (the g.f. identity);
script below. These are the `(1, 3)`-run-length-limited Fibonacci castles of the wiki page
`wiki/pages/fibonacci-castles-sub-families.md`.

## Edit 2 — A003410 castle comment (optional)

### Comment (append)

> For n >= 4, a(n) is the number of castle polyominoes of width n and height 2 in which no two
> columns of height 2 are adjacent and every run of columns of height 1 has length at most 3
> (Project Euler, Problem 502: Counting Castles). Here a castle is a stack of unit blocks on a
> grid, whose bottom row is a single block of length n, whose higher blocks have height 1 and
> rest on the blocks below without overhang, whose maximum height is 2, and in which
> neighboring blocks of the same row are separated by a gap. The second row of such a castle is
> a binary word as in the comment above, and for n >= 4 every such word contains a 1.

The definition sentence is the one used on A038503 / A038505 / A146559.

## Verification script

```python
from itertools import product
import sympy as sp

x = sp.symbols('x')
s = sp.series((1 + x) * (1 + x**2) / (1 - x - x**3), x, 0, 40).removeO()
A003410 = [int(s.coeff(x, n)) for n in range(40)]                 # offset 0
A226136 = [1, 2, 4, 7, 10, 15, 22, 32, 47, 69, 101, 148, 217, 318, 466, 683, 1001, 1467,
           2150, 3151, 4618, 6768, 9919, 14537, 21305, 31224, 45761, 67066, 98290, 144051,
           211117, 309407, 453458, 664575, 973982]                # live, offset 1
assert all(A226136[n - 1] == A003410[n] for n in range(4, 36))
barker = -x * (x + 1) * (x**2 + 1)**2 / (x**3 + x - 1)
assert sp.simplify(barker - ((1 + x) * (1 + x**2) / (1 - x - x**3) - (1 + x) * (1 + x**2))) == 0
for n in range(1, 16):
    words = [''.join(t) for t in product('01', repeat=n)]
    deutsch = [t for t in words if '11' not in t and '0000' not in t]
    castles = [t for t in deutsch if '1' in t]                    # second rows of castles
    assert len(deutsch) == A003410[n]
    assert len(castles) == A003410[n] - (1 if n <= 3 else 0)
print("ok")
```
