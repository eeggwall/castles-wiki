## The facts (verified)

A094706 = "Convolution of Pell(n) and 2^n" (Paul Barry, May 21 2004), offset 0, 31 terms:
`0, 1, 4, 13, 38, 105, 280, 729, …, 624866082400`, g.f. `x/((1-2*x-x^2)*(1-2*x))`. Its Cf. is
`A000079, A000129 (Pell numbers), A101164, A255494`, with no A283595.

A283595 = "Triangle read by rows: T(n,k) is the number of Motzkin prefixes (i.e., left factors
of Motzkin paths) of length n and height k", offset 0, rows `k = 0..n`. Its approved edit
(A283595 #45) added the column g.f. `z^k/(R(k)*R(k+1))` and the crossref "Column k=2 gives
A094706(n-1)."; A094706 has no link back.

1. **A094706(n) = A283595(n+1, 2) for n >= 1** (all 30 listed terms from `n = 1`). For
   `n = 0` the index `(1, 2)` is outside the triangle, since `k <= n`.
2. **Proof**, from A283595's column g.f. at `k = 2`: `R(2) = P(1) - z*P(0) = 1 - 2z` and
   `R(3) = P(2) - z^2*P(0) = 1 - 2z - z^2`, so column 2 is `z^2/((1-2z)(1-2z-z^2))`, which is
   `z` times A094706's g.f.

Verified 2026-11-01: the 30 terms against A283595's Python program, which reproduces its
DATA, and the g.f. identity in SymPy; script below. `bin/python/a283595_column_gf.py` checks
column 2 against A094706 for `n = 2..140`.
