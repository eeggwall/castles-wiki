## The facts (verified)

A097862 = "Triangle read by rows: T(n,k) is the number of Motzkin paths of length n and height
k (n>=0, k>=0)" (Emeric Deutsch, Sep 01 2004), offset 0, keyword `tabf` (row `n` has
`floor(n/2) + 1` terms), 63 terms. Its formulas: "The g.f. for column k is z^(2k)/[P_k*P_{k+1}],
where the polynomials P_k are defined by P_0=1, P_1=1-z, P_k=(1-z)P_{k-1}-z^2*P_{k-2}." and
Alois P. Heinz's `Sum_{k=1..floor(n/2)} k * T(n,k) = A333498(n)`. Its Cf. is
`A001006, A333498`: no A283595, and none of A000225, A027907, A080936, A094706. Neither
A080936 nor A094706 cites A097862.

A283595 = "Triangle read by rows: T(n,k) is the number of Motzkin prefixes (i.e., left factors
of Motzkin paths) of length n and height k", offset 0. Its approved formula (A283595 #45) is
"G.f. of column k: z^k/(R(k)*R(k+1)), where R(2*j) = P(j) - z*P(j-1), R(2*j+1) = P(j+1) -
z^2*P(j-1), P(-1) = 0, and P(k) are the polynomials of A097862", and its Cf. line lists A097862.

Source: `wiki/pages/1-smooth-castles.md` (*Other boundary conditions*, both end columns at
height 1), where `T(n,k)` counts the 1-smooth castles of width `n+1` and height `k+1` whose
first and last columns are at height 1 (neighboring columns differ in height by at most 1;
subtracting 1 from every column gives the Motzkin path).

1. **Both column g.f.s are built from the same polynomials `P_k`**: A097862's
   `z^(2k)/(P_k*P_{k+1})` gives all 63 of its terms, and A283595's `z^k/(R(k)*R(k+1))` gives
   its rows 0..10 (66 terms).
2. **Columns 1 and 2.** `P_1 = 1 - z`, `P_2 = 1 - 2z` and `P_3 = (1 - z)(1 - 2z - z^2)`.
   Column 1 has g.f. `z^2/((1 - z)(1 - 2z))`, so `T(n,1) = 2^(n-1) - 1 = A000225(n-1)` for
   `n >= 2`. Column 2 has g.f. `z^4/((1 - z)(1 - 2z)(1 - 2z - z^2))`, which is `z^3/(1 - z)`
   times A094706's g.f. `x/((1-2*x-x^2)*(1-2*x))`, so `T(n,2) = Sum_{j=0..n-3} A094706(j)` for
   `n >= 4`. Column 2 is the Pell castles (height 3) with both end columns at height 1, the
   running sums of the Pell castles A094706; it has no entry of its own (no match, 2026-10-16).
3. **Dyck paths by height.** Deleting the level steps of a Motzkin path of length `n` with `2j`
   up and down steps leaves a Dyck path of semilength `j` and the same height, and the Motzkin
   path is recovered from that Dyck path and the `2j` positions of its steps. So
   `T(n,k) = Sum_{j=k..floor(n/2)} binomial(n,2*j)*A080936(j,k)` for `k >= 1` (A080936 starts
   at `k = 1`; `T(n,0) = 1`). This is the binomial transform of the wiki page.
4. **`T(n,k) = A027907(n,n+2*k) - 3*A027907(n,n+2*k+2) + 3*A027907(n,n+2*k+4) -
   A027907(n,n+2*k+6)` for `k >= 1` and `n <= 4*k+1`.** Proof (the method of the wiki
   page's §3.7, for walks that end at 0): `A027907(n, n+d)` counts the step sequences in
   `{-1, 0, 1}^n` with sum `d`. The Motzkin paths of length `n` and height at most `k` are the
   walks from 0 to 0 that avoid -1 and `k+1`, and the reflection principle at both walls counts
   them as `Sum_{m} [A027907(n, n+2m(k+2)) - A027907(n, n+2m(k+2)+2)]` over all integers `m`.
   For `n <= 4*k+1` only `m = 0, 1, -1` contribute, both at height `k` and at height `k-1`, and
   the difference of the two sums is the four-term form. The range is sharp: at `n = 4*k+2` the
   right side is `T(n,k) - 1`.

Verified 2026-11-11: the table of Motzkin paths by height, computed by a transfer matrix for
rows 0..200, matches the live DATA and all 10233 terms of the b-file; against that table,
facts 2 to 4 over rows 0..200 (A094706 extended by its recurrence, A080936 and A027907
recomputed and matched to their live DATA), and the failure of fact 4 at `n = 4*k+2` for
`k <= 49`; the castles by brute force for `n <= 11`; script below. Bounded-height path counts
are classical, so the formulas go in without a novelty claim.

import sys
from itertools import product
from math import comb
import sympy as sp

A097862 = [1, 1, 1, 1, 1, 3, 1, 7, 1, 1, 15, 5, 1, 31, 18, 1, 1, 63, 56, 7, 1, 127, 161, 33, 1,
           1, 255, 441, 129, 9, 1, 511, 1170, 453, 52, 1, 1, 1023, 3036, 1485, 242, 11, 1,
           2047, 7753, 4644, 990, 75, 1, 1, 4095, 19565, 14040, 3718, 403, 13, 1, 8191, 48930,
           41392, 13145, 1872, 102]                          # live, offset 0, keyword tabf
A283595 = [1, 1, 1, 1, 3, 1, 1, 7, 4, 1, 1, 15, 13, 5, 1, 1, 31, 38, 19, 6, 1, 1, 63, 105, 64,
           26, 7, 1, 1, 127, 280, 202, 97, 34, 8, 1, 1, 255, 729, 612, 334, 139, 43, 9, 1, 1,
           511, 1866, 1803, 1094, 516, 191, 53, 10, 1, 1, 1023, 4717, 5205, 3465, 1802, 760,
           254, 64, 11, 1]                                   # live, offset 0, keyword tabl
A080936 = [1, 1, 1, 1, 3, 1, 1, 7, 5, 1, 1, 15, 18, 7, 1, 1, 31, 57, 33, 9, 1]  # live, rows 1..6
A094706 = [0, 1, 4, 13, 38, 105, 280, 729, 1866, 4717, 11812, 29365, 72590]   # live, offset 0
A027907 = [1, 1, 1, 1, 1, 2, 3, 2, 1, 1, 3, 6, 7, 6, 3, 1]                   # live, rows 0..3

M = 200
def walks(k, flat=True):
    """Walks on {0, ..., k} from 0 back to 0 with steps +-1 (and 0 if flat), by length 0..M."""
    v, out = [1] + [0] * k, []
    for n in range(M + 1):
        out.append(v[0])
        v = [(v[j-1] if j else 0) + (v[j] if flat else 0) + (v[j+1] if j < k else 0)
             for j in range(k + 1)]
    return out
mot = [walks(k) for k in range(M // 2 + 1)]               # Motzkin paths, height <= k
dyck = [walks(k, flat=False) for k in range(M // 2 + 1)]  # Dyck paths (length 2j), height <= k
T = lambda n, k: mot[k][n] - (mot[k-1][n] if k else 0)
D = lambda j, k: dyck[k][2*j] - (dyck[k-1][2*j] if k else 0)
rows = [[T(n, k) for k in range(n // 2 + 1)] for n in range(M + 1)]
flat = [t for r in rows for t in r]
assert flat[:len(A097862)] == A097862
if len(sys.argv) > 1:                                     # optional: the b-file b097862.txt
    b = [int(l.split()[1]) for l in open(sys.argv[1]) if l.strip() and not l.startswith('#')]
    assert b == flat[:len(b)] and len(b) == len(flat)

# Fact 1: both column g.f.s from A097862's P_k
z = sp.symbols('z')
P = [sp.Integer(1), 1 - z]
for k in range(2, 14):
    P.append(sp.expand((1 - z) * P[-1] - z**2 * P[-2]))
p = lambda j: P[j] if j >= 0 else 0
R = lambda k: p(k//2) - z * p(k//2 - 1) if k % 2 == 0 else p(k//2 + 1) - z**2 * p(k//2 - 1)
def column(gf, N):
    s = sp.series(gf, z, 0, N + 1).removeO()
    return [s.coeff(z, n) for n in range(N + 1)]
c = [column(z**(2*k) / (P[k] * P[k+1]), 14) for k in range(8)]
assert [c[k][n] for n in range(15) for k in range(n//2 + 1)][:len(A097862)] == A097862
c = [column(z**k / (R(k) * R(k + 1)), 10) for k in range(11)]
assert [c[k][n] for n in range(11) for k in range(n + 1)] == A283595

# Fact 2: columns 1 and 2
assert all(T(n, 1) == 2**(n - 1) - 1 for n in range(2, M + 1))
a = A094706[:3]
while len(a) < M: a.append(4*a[-1] - 3*a[-2] - 2*a[-3])  # from its g.f. x/((1-2x-x^2)(1-2x))
assert a[:len(A094706)] == A094706
assert all(T(n, 2) == sum(a[:n - 2]) for n in range(4, M + 1))

# Fact 3: Dyck paths by height
assert [D(j, k) for j in range(1, 7) for k in range(1, j + 1)] == A080936
assert all(T(n, k) == sum(comb(n, 2*j) * D(j, k) for j in range(k, n // 2 + 1))
           for n in range(M + 1) for k in range(1, n // 2 + 1))

# Fact 4: the trinomial form, n <= 4k+1, and its failure at n = 4k+2
tri = [[1]]
for n in range(M):
    r = tri[-1]
    tri.append([(r[j] if j < len(r) else 0) + (r[j-1] if 0 <= j-1 < len(r) else 0)
                + (r[j-2] if 0 <= j-2 < len(r) else 0) for j in range(len(r) + 2)])
assert [t for r in tri[:4] for t in r] == A027907
t = lambda n, j: tri[n][j] if 0 <= j <= 2*n else 0
F = lambda n, k: t(n, n+2*k) - 3*t(n, n+2*k+2) + 3*t(n, n+2*k+4) - t(n, n+2*k+6)
assert all(F(n, k) == T(n, k) for k in range(1, M // 2 + 1) for n in range(min(4*k+1, M) + 1))
assert all(F(4*k + 2, k) == T(4*k + 2, k) - 1 for k in range(1, (M - 2) // 4 + 1))

# Castles: 1-smooth, first and last columns at height 1, width n+1, height k+1
for n in range(12):
    count = [0] * (n + 2)
    for steps in product((-1, 0, 1), repeat=n):
        col = [1]
        for s in steps:
            col.append(col[-1] + s)
        if min(col) >= 1 and col[-1] == 1:
            count[max(col) - 1] += 1
    assert all(count[k] == T(n, k) for k in range(n // 2 + 1))
print("ok")
